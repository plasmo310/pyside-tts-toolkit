tts コマンド早見表

セットアップが済んだ状態から、やりたいことごとにコマンドを引くためのページ。 導入手順は docs/setup/ を参照。

準備 最初に一度

コマンドはすべてリポジトリのルートで実行する。パスが長いので alias を張る。

PowerShell（このシェルの間だけ有効）
> cd python-tts-sample
> function tts { & "$PWD\.venvs\common\Scripts\python.exe" -m tts_sample @args }

環境が正しいか確認する。CUDA OK が 3 つ出れば準備完了。

動作確認
> tts doctor
> tts engines   # エンジン一覧と対応機能
outputs/ 生成した wav の置き場 voices/ マスター音声の置き場 samples/ 台本とバッチ入力の例

1 本しゃべらせる tts synth

いちばん基本の形。まずは軽い chatterbox で試すのが早い。

テキストを直接渡す
> tts synth --engine chatterbox --text "こんにちは。" --lang ja --out outputs\hello.wav

[chatterbox] D:\...\outputs\hello.wav
  24000 Hz / 2.52 秒 / 生成 4.22 秒
長い台本はファイルから（UTF-8）
> tts synth --engine irodori --text-file script.txt --lang ja --out outputs\a.wav
同じ結果を再現したいときはシードを固定
> tts synth --engine qwen --text "こんにちは。" --lang ja --seed 42 --out outputs\b.wav
話速を変える（irodori のみ・1.0 が等速）
> tts synth --engine irodori --text "ゆっくり話します。" --lang ja --speed 0.8 --out outputs\slow.wav

オプション一覧

オプション説明
--engine必須。 qwen / chatterbox / irodori
--text必須（または --text-file）。合成するテキスト
--text-fileテキストをファイルから読む（UTF-8）
--out必須。 出力 wav のパス
--langja / en。省略するとエンジンの既定
--ref参照音声 wav（声のクローン）
--ref-text参照音声の書き起こし。qwen のみ使う
--voice-design文章で声を設計。qwen / irodori のみ
--seed乱数シード
--speed話速。irodori のみ
--verboseエンジンのログをそのまま表示する
対応していないオプションはエラーになる

黙って無視されることはない。判定はモデルを読み込む前に行われるので、 待たされずにすぐ失敗する。

オリジナルの声を作る --voice-design

文章で声の特徴を書くと、実在の人物に依存しない声を作れる。 ただし生成のたびに少しずつ変わるので、気に入った声は マスター音声に固定して、以降はそれをクローンして使う。

  1. 声を試す — 指示文を変えて何本か作って聴き比べる
    seed は固定しておくと、違いが指示文によるものだと分かる
    > tts synth --engine irodori --seed 42 --lang ja --out voices\try01.wav `
      --voice-design "落ち着いた低めの女性の声。丁寧で穏やかな話し方。" `
      --text "この声でどうでしょうか。"
  2. マスター音声にする — 長めの台詞で 1 本だけ作って保存
    irodori は 30 秒以上あると安定する（上限 120 秒）
    > tts synth --engine irodori --seed 42 --lang ja --out voices\reimu_master.wav `
      --voice-design "落ち着いた低めの女性の声。丁寧で穏やかな話し方。" `
      --text-file voices\master_script.txt
  3. 以降はクローンして使う — 声がぶれなくなる
    --voice-design ではなく --ref を使う
    > tts synth --engine irodori --ref voices\reimu_master.wav `
      --text "マスター音声から再現した声です。" --lang ja --out outputs\a.wav
  4. 英語版も同じ声で — マスター音声を qwen に渡す
    irodori は英語を出せないので、ここだけエンジンを替える
    > tts synth --engine qwen --lang en --ref voices\reimu_master.wav `
      --ref-text "こんにちは。私はこのキャラクターの声です。" `
      --text "This is the same character speaking English." --out outputs\en.wav

指示文の書き方

次の軸で書く。全部詰め込むより 3〜4 要素に絞るほうが安定する。

軸例
性別・年齢若い女性、少年、中年の男性、老人
声の高さ・質低め、高め、掠れた、澄んだ、ハスキー
話し方丁寧、ぶっきらぼう、早口、ゆっくり、淡々と
感情・態度楽しそうに、呆れたように、落ち着いて
実際に使える指示文の例
落ち着いた低めの女性の声。丁寧で穏やかな話し方。
元気で明るい少女の声。やや早口で、楽しそうに話す。
少し掠れた低い男性の声。ぶっきらぼうだが芯がある。
エンジンごとの制約

chatterbox は Voice Design に非対応（クローンのみ）。 qwen は --voice-design と --ref を併用できない。 irodori は併用でき、そのときは声質＝参照音声・話し方＝指示文になる。 日本語の声を作るなら irodori が確実。

声をクローンする --ref

参照音声を渡すだけ。3 エンジンとも対応している。

chatterbox / irodori — 書き起こしは不要
> tts synth --engine chatterbox --ref voices\alice.wav `
      --text "クローンした声で話しています。" --lang ja --out outputs\a.wav
qwen — 書き起こしを渡すと品質が上がる
> tts synth --engine qwen --ref voices\alice.wav `
      --ref-text "参照音声で実際に話している内容" `
      --text "おはようございます。" --lang ja --out outputs\b.wav
エンジン参照音声の長さ書き起こし
qwen3 秒〜あると品質が上がる
chatterbox10 秒前後不要
irodori30 秒以上を推奨（上限 120 秒）不要

いずれもノイズ・BGM のないきれいな音声を使う。

台本からまとめて作る tts script

複数のキャラクターが会話する台本から、台詞ごとの wav を一度に作る。 声の定義と台詞を別ファイルに分けるので、台本には「誰が」「何を」しか書かない。

① cast.toml — キャラクターの声。最初に一度だけ書く
# 日本語名はクォートが必要（[voices.霊夢] は構文エラー）
[voices."霊夢"]
engine = "irodori"
voice_design = "落ち着いた少女の声。淡々と話す。"
language = "ja"
seed = 42

[voices."魔理沙"]
engine = "irodori"
reference_audio = "../../voices/marisa.wav"   # この toml からの相対
language = "ja"

[voices."ナレーター"]
engine = "qwen"
language = "ja"
② ep01.ja.txt — 台詞。毎回書くのはこちらだけ
# ■ オープニング

ナレーター: ある晴れた日のこと。

霊夢: 今日はいい天気ね。
魔理沙: そうだな、絶好の弾幕日和だぜ！

霊夢[speed=0.9]: ……また変なこと言ってる。
魔理沙[id=punchline]: やった、ごちそうさま！

# インデントで長い台詞を折り返せる
霊夢: まあいいわ。
  お茶でも淹れてくるから、
  そこで待ってなさい。
③ 実行する
> tts script --cast samples\script\cast.toml --script samples\script\ep01.ja.txt --outdir outputs\ep01

7 台詞 / 3 キャラクター / エンジン: qwen, irodori

--- qwen (1 台詞) ---
[001] ナレーター  1.84秒  ある晴れた日のこと。

--- irodori (6 台詞) ---
[002] 霊夢  2.64秒  今日はいい天気ね。
[003] 魔理沙  3.84秒  そうだな、絶好の弾幕日和だぜ！
...

7/7 台詞を生成。合計 23.8 秒

台本の書き方

書き方意味
話者: 台詞1 行 1 台詞。コロンは半角でも全角でもよい
# コメント無視される。セクションの見出しに使う
（空行）無視される。場面の区切りに自由に入れてよい
　インデント行直前の台詞の続き。区切り文字なしで連結される
話者[key=値]: 台詞その台詞だけ上書き。id speed seed lang
英語の台詞はインデント継続を使わない

継続行は区切り文字なしで連結されるので（日本語に空白が入らないようにするため）、 英語だと Hello.How are you? のように単語がくっつく。1 行に収めること。

出力

outputs/ep01/ 001-ナレーター.wav 002-霊夢.wav 003-魔理沙.wav … 007-punchline.wav ← [id=punchline] を付けた台詞 manifest.json ← 台詞ごとの尺と開始位置

ファイル名の先頭が台本の並び順。manifest.json には 先頭からの累積オフセット（start_sec）が入るので、Remotion の <Sequence from={...}> にそのまま使える。

モデルの読み込みは 1 エンジンにつき 1 回

エンジン単位でまとめて処理するので、進捗表示は台本順ではなくエンジンごとに まとまって出る。キャラクターを増やしてもエンジンが同じなら追加コストはない。

台本の詳しい仕様は docs/guide/script.md、 声の作り方は docs/guide/original-voice.md にある。

JSON からまとめて作る tts batch

台本を使わず、機械的に生成した JSON から流したいときはこちら。 キャラクターの概念はなく、1 行 = 1 リクエスト。

入力 JSON
[
  {"id": "line-001", "text": "こんにちは。", "language": "ja"},
  {"id": "line-002", "text": "今日はいい天気ですね。", "language": "ja", "seed": 42},
  {"id": "line-003", "text": "クローンもできます。", "language": "ja",
   "reference_audio": "ref/alice.wav"}
]
実行する
> tts batch --engine qwen --input samples\input.ja.json --outdir outputs\batch
  • 使えるキー: id text language reference_audio reference_text voice_design seed speed
  • reference_audio は入力 JSON からの相対パスで解決される
  • 1 件失敗しても続けたいときは --keep-going

どのエンジンを使うか

エンジン 日本語 英語 クローン 声の設計 話速 速度
qwen ○○ ○○ ×遅い
chatterbox ○○ ○× ×速い
irodori ○× ○○ ○速い
  • まず試すなら chatterbox — 軽くて速い
  • 日英を同じ声で出すなら qwen — 1 本で両言語をまかなえる
  • 日本語のキャラクターなら irodori — 48 kHz で表現力が高い。ただし英語は出せない
日英の両方が要るとき

irodori で日本語の声を作ってマスター音声に固定し、 英語版はそれを --ref で qwen か chatterbox に渡す。 同一人物に聞こえるかは必ず耳で確認すること。

困ったとき

症状対処
未構築 と出る tts engines で確認し、 pwsh scripts\setup_engines.ps1 -Engines irodori で個別に作り直す

タイムアウトする TTS_SAMPLE_READY_TIMEOUT（既定 1800 秒）と TTS_SAMPLE_SYNTH_TIMEOUT（既定 900 秒）で延ばせる
日本語が文字化けする ターミナルのコードページを確認する（chcp 65001）
毎回違う声になる --seed を固定する。Voice Design はマスター音声に固定して --ref に切り替える
