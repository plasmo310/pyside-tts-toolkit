TTSを使ってテキストから音声ファイルを出力するスクリプトを作ってほしい。
各TTSの調査結果はdocs\references\20260921_01_tts.mdを参照。
今回は、以下の3つのモデルを使用したサンプルを作成する。

- Qwen3-TTS
- Irodori-TTS
- Chatterbox

入力、出力はなるべく共通にして、モデル使用は抽象化したラッパーを作成して使用する。
将来的にはGUIを用意することも考慮する。
各モデルのセットアップ手順（一からの導入方法や参照先のURLリンクも含む）については、docs/setup配下に格納する。

miseを導入しているので、pythonはそちらからインストールしたものを使用してください。
